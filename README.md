# Internet-of-Things with Python in Cisco Packet Tracer
This repository contains a collection of mini IoT projects developed using Python in Cisco Packet Tracer as part of university coursework.

The projects focus on simulating IoT environments, processing device data, and applying basic automation logic. While each project is small in scope, together they demonstrate foundational skills in:
- Python-based data handling
- Event-driven logic and automation
- Simulated networked systems
- Structured problem-solving
